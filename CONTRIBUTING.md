# Contributing to DeadBot

Thank you for your interest in contributing to DeadBot!

## How to contribute

We welcome **well-thought-out ideas, bug fixes, and improvements** that help the project grow.

Before submitting a pull request (PR), please:

- Search existing issues and PRs to avoid duplicates.
- Open an issue first if your change is non-trivial or requires discussion.
- Keep your PR focused and concise.
- Write clear commit messages.

## What we don't accept

- Spam, low-effort contributions, or off-topic requests.
- Large feature requests without prior discussion.
- Code or PRs without tests or documentation when applicable.

## Communication

We appreciate respectful and constructive communication. If you have questions or need help, open an issue.

---

*Note: This is a one-person project with limited time. Contributions are welcome but will be reviewed carefully.*
